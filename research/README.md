# Research

Research projects kept alongside the openGym code. They are documentation only: nothing here is built, shipped or run by openGym.

| Project | Date | Question | Start with |
|---|---|---|---|
| [delva-evidence-review](delva-evidence-review/README.md) | 2026-11-07 (archived 2026-11-11) | Which open-source projects and research papers matter for Delva, a vision-guided home fitness app, and what should it learn from each? | [Overview](delva-evidence-review/README.md), then the [report](delva-evidence-review/01-report/report.md) |

## Conventions for a project folder

Each project uses the same numbered layout so the next one is easy to read:

| Folder | Holds |
|---|---|
| `00-brief/` | The request verbatim, and how it was interpreted |
| `01-report/` | The final deliverable |
| `02-notes/` | The evidence behind it |
| `03-process/` | How the work was done: timeline, tools, agents, limits, incidents |
| `04-data/` | Working data and scripts, plus a manifest of anything left out |
| `05-next-steps/` | Open questions and how to resume |

Third-party documents (papers, PDFs, legal texts, web pages) are not committed, because this repository is public. Projects list them in a manifest with their checksums instead.
