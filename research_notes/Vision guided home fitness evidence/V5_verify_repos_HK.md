# V5: Repository metadata for areas A, B, C, H/K, and a check of the H/K papers and standards

Date checked for every number in this file: **2026-11-07**.

**How the numbers were collected**
- **Stars, last push, archived flag, GitHub licence (SPDX), owner and owner type:** `gh api -X GET search/repositories -f q='repo:OWNER/NAME ...'`, run in batches on 2026-11-07. The owner type is GitHub's own field: "Org" means a GitHub organisation account, "User" means a personal account. The description (company, lab, individual) comes from the notes and the repo itself.
- **Contributors:** these are **distinct commit-author emails on the default branch, which approximates GitHub's contributor count**. They come from `git clone --bare --filter=tree:0` followed by `git log --format='%aE' | sort -u | wc -l`. The **last commit** date is `git log -1 --format=%cI` on the default branch. Every clone was deleted after it was measured. One person with several emails is counted more than once, and bots are counted too (removing bot-like emails changed totals by 5 at most).
- **GitHub's own contributor number** could not be read. `curl` to github.com web pages is refused by this session's proxy (HTTP 403), and WebFetch of `github.com/wger-project/wger` showed the "Contributors" heading with no number. The commit count WebFetch did show (9,769) matches the git count exactly. So the contributor column holds only the git-email count.
- **Licence text:** read from the LICENSE, NOTICE and README files at HEAD, through the partial clone or raw.githubusercontent.com. Rows where GitHub reports `NOASSERTION` or `null` were checked by reading the actual file.
- **Credibility bar** (from the brief): at least 1,000 stars, **or** a lab or company plus a peer-reviewed paper. A repo also has to be active, meaning a last commit on or after **2025-05-07** (18 months before the check date), unless it is archived but influential. "Stale" means the last commit is older than that.
